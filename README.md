# 🏏 IPL 2025 - Batting Intent Analysis

This project dives deep into analyzing **batting intent** during the **Indian Premier League 2025**, leveraging Python and Jupyter Notebooks. The objective is to uncover patterns in batting behavior, shot selection, and aggression based on match scenarios.

---

## 📊 Project Highlights

- 📌 **Season Analyzed**: IPL 2025  
- 🔍 **Focus**: Batting intent based on over, score, and opposition  
- 🧠 **Tech Stack**: Python, Pandas, Matplotlib, Seaborn, Jupyter  
- 📁 **Data Source**: Custom dataset (included)
